Страницы `/diet` в репозитории нет: `frontend/` содержит единственный
`index.html`, `vite.config.ts` собирает один вход (без multi-page `rollupOptions.input`),
упоминаний `diet` в `frontend/` и `docker-compose.yml` нет. Проверено при полном
пересканировании на коммите `1bf57c3` (03.08.2026).

**Why:** в пользовательской авто-памяти есть более старая запись «diet static page —
задеплоена, но не закоммичена». Она описывала состояние живого контейнера, а не
репозитория; в git это никогда не попало и в текущем дереве не существует.

**How to apply:** не считать `/diet` частью проекта при сканировании или правках
фронта. Если страница нужна снова — это новая работа с нуля; если она всё ещё
отдаётся боевым nginx, значит живёт только в образе и пропадёт при следующей
пересборке `frontend`.
